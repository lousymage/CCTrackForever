# Changelog

## 0.1

- First public release for WoW: Forever 1.60.1 (interface 16001).
- Track your own crowd control, silences, and debuffs across multiple targets.
- Use aura durations when available and estimate timers from finished casts when aura access is blocked.
- Refresh the Frostbolt timer on the same selected target when the client hides its name and GUID.
- Adjust bar size, position, and growth direction. Settings are saved per character.
